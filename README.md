# 星语 StarVox 1.1

本地 AI 伙伴聊天应用，电脑和手机共用同一套聊天、记忆与备份功能。

## 启动（服务端环境变量版）

需要 Node.js 22.9 或更新版本，推荐 Node.js 24。在项目目录执行：

```powershell
npm ci
npm run setup:models
Copy-Item .env.example .env.local
```

在本机编辑 `.env.local`，填写 `DEEPSEEK_API_KEY`，保存后运行：

```sh
npm run dev -- --host localhost --port 5173 --strictPort --open
```

也可以双击「启动聊天站.bat」。继续使用原来的浏览器与 http://localhost:5173 可访问原有本地聊天数据。修改环境变量后需要重启服务。

连接页只选择模型并测试连接。测试会向 DeepSeek 发起一次小请求。密钥仅由 Node 服务读取，不进入浏览器配置、备份或 Web 构建文件；不要使用 `VITE_` 前缀保存密钥。`.env.local` 和真实环境配置均被 Git 排除，仓库只包含空的 `.env.example`。

构建后的本机运行：

```sh
npm run build
npm start
```

服务仅监听本机地址，代理拒绝非本机访问和跨站来源。这个版本的聊天功能需要 Node 服务；GitHub Pages 等纯静态托管没有环境变量后端。不要直接公开此本机代理；对外部署需要先实现登录、访问控制和费用限制。Android 原生工程保留，但独立 APK 无法使用本机 Node 代理，需另外配置受保护的后端后才能聊天。

本地语义检索资源通过 `npm run setup:models` 从固定版本下载并校验 SHA-256，WASM 从锁定依赖复制。资源随后从本机加载；`public/models`、`public/wasm` 不上传 Git。首次准备模型需要网络，也可以保留原有已校验模型。

## 已完成的升级

- 多会话：新建、切换、改名、删除、标题与正文搜索；每段对话独立保存草稿、图片、情绪和人格设定。
- 消息操作：复制、收藏、当前对话搜索、编辑分支、重新生成、失败重试、Markdown 文本导出。编辑和重试会建立分支，原对话保留。
- 可靠生成：本轮输入只提交一次；停止立即生效；失败和中断保留已收到的内容，刷新后的中断回复可重试。只有成功完成的回复更新情绪与提炼记忆。
- 长期记忆：按人格共享与隔离，支持查看、编辑、检索、关键词补全、历史重建、导出与清空；失败任务可重试。同人格的不同会话及分支共享记忆，并不是互相隔离的世界线。
- 图片：每条最多 3 张，在本地压缩、预览和移除后发送；当前仅向支持图像的 Flash 配置发送。可选择一张本地图片作为角色形象。
- 语音：浏览器支持时可把说话转成输入文字，并朗读回复，选择语音与语速、随时停止。识别可能使用浏览器提供商的在线服务；发送文本仍由你确认。
- 手机：侧栏收成抽屉，保留完整记忆、备份、加密与人格功能；触屏回车换行，点击发送。查看旧消息时不会被回复强制拉回底部。
- 数据：兼容旧存档与旧版备份，全部会话参与本地加密；存储不足时显示错误，不再自动截断历史；完整恢复失败会尝试回滚原有数据。

## 备份与恢复

侧栏「备份与恢复」可导出全部会话、草稿、附件、角色设定与全部人格的记忆。备份始终不含 API Key；可选择包含模型与思考设置。导入旧备份时密钥字段会被忽略，聊天与记忆仍可恢复。文件是明文 JSON，即使应用启用了本地加密也一样，请妥善保管。

选择备份文件后会先展示数量，点击确认恢复才写入。恢复会替换本机的对话列表，并覆盖备份中相应人格的记忆；未出现在备份中的人格记忆保留。先导出当前备份再恢复较稳妥。

浏览器存储有容量限制，图片会更快占用空间。保存失败时，当前页面内容仍可导出；请先备份，再删除不需要的会话释放空间。清除浏览器数据、换浏览器或换端口，不会自动迁移聊天；可用备份搬运。

本地加密需要口令，忘记口令无法解密；请同时保留一份可用的离线备份。

安卓安装包导出备份、记忆、聊天文本和图片时，会打开系统保存窗口，由你选择位置；取消保存不会显示成功。浏览器版使用浏览器的下载功能。

## 数据会去哪里

聊天请求会向 DeepSeek 发送系统设定、相关历史、检索到的记忆及本轮文字和所选图片。记忆提炼、关键词补全与重建也会发送相关内容，可能产生 API 费用。应用没有账号系统、统计埋点或云同步。语义检索模型与运行时随项目本地加载。

语音输入和朗读取决于浏览器/系统支持，部分语音服务会联网。未支持时界面会明确提示。服务端环境变量中的 API Key 只用于 DeepSeek 请求。浏览器仅访问同源代理。

## 开发与验证

```sh
npm test
npm run build
npm run check:publish
```

回归测试使用合成数据和模拟网络，不消耗真实 API 额度。Web 构建产物在 dist；Android 工程在 android，需要已有 JDK 21 与 Android SDK。已配置中文路径支持，请自行设置本机 JAVA_HOME。Android 打包命令为在 android 目录运行 gradlew.bat assembleDebug，调试包不等于商店发行包。

主要代码：ChatPage.jsx 是共用聊天工作区；turn.js / deepseek.js 负责请求；memory.js 管理人格记忆；storage.js / crypto.js 管理会话、备份和加密；media.js / useSpeech.js 负责图片与声音。

## 仍需外部条件的部分

目前有情绪驱动头像与自定义静态图片，尚未集成真正的 Live2D 模型、动作或口型；需要合适的模型及运行库授权。语音是输入转文字和回复朗读，不是连续实时语音通话。没有实现账号、云端同步或多设备自动同步。

真实 API 成功率、麦克风和声音输出需要在你的环境与设备上实测；自动测试不会代替这一步。
